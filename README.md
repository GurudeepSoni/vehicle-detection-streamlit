🚗 Vehicle Detection App

A simple yet powerful vehicle detection web app built using Streamlit, YOLO, and OpenCV.
Upload any vehicle video and download the processed output with detections.

--------------------------------------------------

🔗 Live Demo
https://vehicle-detection-app-kwrhor4dtwwsjqmardkb3s.streamlit.app/

--------------------------------------------------

🛠 Features
✨ Vehicle detection using YOLO (You Only Look Once)
🎥 Upload video (.mp4 / .avi)
📊 Shows live processing percentage
⬇️ Download processed output video
🌐 Fully deployed on Streamlit Cloud
👨‍💻 Created by Gurudeep Soni

--------------------------------------------------

📌 How It Works
1. User uploads a vehicle video
2. Video is processed frame by frame using YOLO
3. Bounding boxes are drawn on detected vehicles
4. Output video is generated
5. User downloads the processed result

--------------------------------------------------

📦 Tech Stack
🐍 Python – Core language  
🚗 OpenCV – Video processing  
🤖 YOLOv8 – Object detection  
🌐 Streamlit – Web UI & deployment
